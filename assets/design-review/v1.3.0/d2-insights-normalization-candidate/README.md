# Oneiros 1.3.0 — D2 Insights normalization candidate

Review-only candidate for the eight existing Insights concepts. It preserves the
current source PNGs and their alpha silhouettes. The comparison applies only:

- optical-scale calibration;
- a shared Deep Ink treatment from the existing Oneiros palette;
- common rendering opacity at review time.

It does not redraw a symbol, introduce a colour, modify the approved logo, or
change runtime code. Open `index.html` through the repository review server.

Any concept that still feels wrong after normalization must be flagged for the
separate D3 conceptual review. It must not be redesigned inside D2.
