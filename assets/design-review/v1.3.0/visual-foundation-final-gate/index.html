Freeze statement

Oneiros Visual Foundation v1.3.0 is locked.

Palette, typography roles, cards, borders, radii, CTA, navigation states, spacing, icon containers, shadows, parchment background and responsive shell are closed. The only future visual work is a separately opened Icon Redesign Phase. This gate does not authorize icon concepts, silhouettes, artwork or runtime replacements.

Browser QA is not proof of native-only safe areas, rendering, microphone, biometrics, haptics or store behavior. Those remain release-verification responsibilities and do not reopen the visual foundation unless a confirmed defect is found.
