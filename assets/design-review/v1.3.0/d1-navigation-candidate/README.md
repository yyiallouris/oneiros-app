# Rejected D1 conceptual navigation candidate

**Status: REJECTED — DO NOT IMPLEMENT.**

This board attempted new silhouettes and therefore exceeded the approved
normalization-only scope for `v1.3.0-d1-navigation`. Nothing in this directory
is imported by the application, and none of these SVGs may be promoted.

`manifest.json` records the exact candidate SVG hashes reviewed in this round.
Any geometry edit requires regenerating those hashes before the next review.

## Construction

- Common 24-unit grid.
- Vector-first, mostly outline marks.
- Plum in the standalone SVGs exists only for convenient review; runtime state
  colour remains token-owned if the family is approved.
- Write retains the feather concept but removes dense dry-brush mass.
- Journal retains the open-dream-journal concept with deliberate page
  asymmetry and one quiet page-memory gesture per side.
- Insights relates to the approved eye/river identity through unequal eye lids
  plus one restrained filled river gesture. It is a simplified navigation
  relative, not a redraw or substitute for the locked brand master.
- No selection dot, badge, pill, glow or detached ornament.

## Archive reason

The eye competed with the locked logo language, and all three marks moved from
art-direction normalization into conceptual redesign. The replacement review
scope lives in the sibling `d1-navigation-normalization-candidate` directory.
