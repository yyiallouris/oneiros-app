# Oneiros Journal — before / after

Both screenshots come from the running Expo application in design-export mode, captured through Chrome at a fixed 390 × 844 viewport. They are not redrawn mockups.

- `01-before-app-390x844.png` — the clean but geometrically neutral Journal icon before the authored-gesture refinement.
- `02-after-app-390x844.png` — the current Journal icon from a fresh build of the repository.
- `03-before-after-side-by-side.png` — the same two app screenshots presented at their original 390 × 844 size.

## Journal changes

- Preserved the light open-journal concept and 30dp navigation size.
- Introduced subtle page-height and opening asymmetry.
- Gave the lower page curves unequal cadence instead of mirrored geometry.
- Replaced the mechanical vertical spine with a softly wandering ink line.
- Varied stroke pressure across page edges and inner traces while retaining rounded endings and joins.
- Removed the witness dot completely. Active state now comes only from ink colour and opacity.
- Left the feather and Insights navigation marks unchanged.
