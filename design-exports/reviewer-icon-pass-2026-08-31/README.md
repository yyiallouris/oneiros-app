# Oneiros icon pass — reviewer before/after

This packet shows the correction made after the reviewer feedback.

## Reading order

1. `01-monochrome-representative-proof.png` — enlarged comparison of Journal, Images, and Thresholds in one common black ink. This is the primary drawing-character test; colour cannot create false consistency.
2. `02-journal-and-calendar-before-after.png` — Journal refinement and Calendar reversion at actual UI size.
3. `03-microphone-before-after.png` — Microphone reversion at actual UI size.
4. `04-insights-before-after.png` — complete Insights family at actual UI size.

In every screen comparison, **left is BEFORE REVIEW CORRECTION** and **right is AFTER REVIEW CORRECTION**.

## Scope reflected in the after version

- Every existing icon concept and silhouette is preserved by default.
- Insights icons return to their original black ink; the global purple recolour is reverted.
- Insights artwork is not redrawn. Only restrained per-icon optical scale is used where mass was excessive.
- Journal is the sole approved redesign. It keeps the open-journal concept, with lighter asymmetric pages, a softer spine, and a substantially quieter active witness dot.
- Calendar and Microphone replacements are reverted to their original Oneiros artwork.
- Navigation, Insights, and functional icons remain distinct subfamilies rather than being forced into identical density.

The `before-review-correction/` and `after-review-correction/` folders contain the raw screen captures used to build the labelled comparisons.
